Ben's Neovim Config
===================

Plugins:
--------

**Lazy.nvim**
- Plugin manager

**Onedark.nvim**
- Onedark colorscheme

**Mason.nvim / mason-lspconfig.nvim**
- Lsp manager

**Mini.nvim**
- Nerd font helper for status line

**Gitsigns.nvim**
- Shows git tracking status of the file

**Nvim-web-devicons**
- Adds more icons

**Which-key.nvim**
- Shows keybinds after an interval

**Todo-comments.nvim**
- Adds highlighting for certain comment patterns

**Nvim-treesitter**
- Adds better syntax highlighting based on language features

**Nvim-treesitter/playground**
- Show the AST of the file being worked on

**Lualine.nvim**
- Customize the status line

**Harpoon**
- Jump between files with one keybind

**Lsp-zero.nvim / Lspconfig / cmp-nvim-lsp / nvim-cmp / cmp-buffer**
- Add better lsp support, auto complete, etc.

**Luasnip / nvim-autopairs**
- Automatically add paired symbols

**Undotree**
- Change the structure of undo / redo to be a tree rather than a list

**Vim-fugitive**
- Make git transactions within neovim
